# UI/UX Job Tracker

安徽 UI/UX、交互、设计组长与设计管理岗位每日采集与追踪项目。由 WorkHunter 定时任务（工作日每天 9:00）调用 `$anhui-design-job-hunter`，在 Chrome 中采集、核验、清洗、比对并推送更新。

## 在线仪表盘

https://skylerlee88.github.io/ui-ux-job-tracker/

仪表盘支持按城市、企业类型、平台筛选，卡片点击展开详情，含直接投递链接。每次数据推送后自动更新。

## 目录结构

```
├── index.html            # 在线仪表盘（GitHub Pages 入口，每日自动同步）
├── data/
│   ├── template.csv      # CSV 字段模板
│   ├── jobs_YYYY-MM-DD.csv   # 每日岗位数据（最新）
│   ├── jobs_dashboard.html   # 仪表盘源文件
│   └── daily/            # 每日数据备份（用于新增岗位比对）
└── reports/
    └── YYYY-MM-DD.md     # 每日日报（采集概况 / 分布 / 重点推荐 / 薪资分析）
```

## CSV 字段

日期, 平台, 岗位名称, 公司名称, 公司类型, 城市, 薪资范围, 经验要求, 学历要求, 岗位链接, 公司工商验证, 招聘信息验证, 备注, 是否新增

## 采集范围

- 关键词：UI设计师 / UX设计师 / 交互设计师 / 用户体验设计师 / 设计组长 / 设计主管 / 设计经理 / UED负责人
- 城市：安徽省全域
- 企业类型：央企、国企、国资控股、上市或万人以上民企、500强外企
- 平台：企业官网、国聘、猎聘、智联招聘、前程无忧、BOSS直聘、LinkedIn等

## 更新机制

每个工作日 9:00，WorkHunter 定时任务自动执行：Chrome浏览 → 招聘状态验证 → 与前日比对标注新增 → 生成 CSV/日报/仪表盘 → commit & push 到本仓库。遇到登录或验证码时会保存检查点并等待用户在 Chrome 中处理，未完成核验的数据不会冒充有效岗位发布。
